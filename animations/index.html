跑起来看（按钮能动）

在仓库根目录的 Claude 会话里说"打开第 N 章动画"即可（.claude/launch.json 里的 cuda-animations 配置）。自己在终端跑：

python3 -m http.server 8349 --directory cuda-programming/notes/animations

然后浏览器打开 http://localhost:8349/01-thread-index.html（换成对应文件名）。

新增或修改一个动画

  1. 第 1 章是手写的 01-thread-index.html；第 2–27 章由生成器产生：源文件在仓库根目录 work/cuda-anim/specs/NN-*.js（开头用 // key: value 写标题、说明、开关和统计，其余是绘图脚本），共用的绘图小工具在本目录 cuda-anim.js。改完运行：

bash python3 work/cuda-anim/gen.py

页面统一引用 anim.css、anim.js（从 pytorch-deep-dive/notes/animations/ 复制来的同一套）和 cuda-anim.js，提供 reset() 和 next()（返回 false 表示播完），用 setupPlayer({captureSeed, reset, next}, 毫秒) 挂上播放按钮。 2. 重新录 GIF（在本目录下执行）：

bash node ../../../tools/anim-capture/capture.mjs 02-block-waves.html 02-block-waves.gif 1400

录完删掉多出来的 *-last.png。 3. 在对应讲义的"讲解"末尾写 ### 动画演示，然后跑 tools/notes-sync/sync.sh cuda-programming "CUDA"，再跑 python3 tools/gallery/build.py。
