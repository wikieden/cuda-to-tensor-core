第 11 章 · shuffle down 与 shuffle xor

配套讲义：第 11 章 · warp shuffle 与原子操作：不经过 shared memory 交换数据。8 个 lane 代表一个 warp 的 32 个。格子里是这个 lane 寄存器里的值；箭头是"谁从谁那里拿值"。

shuffle 次数
shared memory 访问
block 同步

看点：① down：每步 lane t 加上 lane t+d，最后只有 lane 0 是总和（金色）；② xor：lane t 和 t^m 互换相加，最后每个 lane 都是总和；③ 全程不碰 shared memory、不需要 __syncthreads()。
