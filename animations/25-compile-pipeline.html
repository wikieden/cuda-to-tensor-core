配套讲义：第 25 章 · 编译与部署：PTX、cubin、fatbin、JIT，以及 Rust host + C++ kernel。nvcc 把 host 代码交给 C++ 编译器，device 代码编成 PTX 再编成 cubin，装进 fatbin。运行时驱动从 fatbin 里挑最合适的一份。

驱动选中
要不要 JIT
能用 wgmma 吗

看点：① fatbin 里有 sm_80、sm_90a 两份 cubin 和一份 compute_90 PTX；② A100 → sm_80 cubin，H100 → sm_90a cubin；③ 未来的新卡没有现成 cubin，PTX 现场 JIT 编译并写入缓存，但用不了 sm_90a 专属的 wgmma。
