配套讲义：第 1 章 · 一个 kernel 怎么分给成千上万个线程：grid / block / thread 与全局编号。上排是线程（按 block 框起来），下排是数组元素。每个线程用 i = blockIdx.x × blockDim.x + threadIdx.x 找到自己负责的那一格。
